# 微信随手记 (WeChat Diary)

**对着微信说话, 内容自动落进你自己电脑的 Obsidian 库。**

![对着微信说一句话, 它就出现在你的 Obsidian 日记里](docs/images/hero.png)

微信是中文用户一天里打开最频繁的输入框。这个插件把它变成一条零摩擦的采集管道: 扫码绑定一次微信 bot, 之后随时在手机上发文字、语音、图片给它——只要电脑上的 Obsidian 开着, 每条消息都会追加到库里的 `日记/YYYY/YYYY-MM-DD.md`。纯 Markdown, 全部在你自己的机器上。

日记、备忘录、灵感、给爸妈记的病历——发出去, 就记下了。

## 功能

- **发什么记什么, 不用任何开场白**: 不需要说「开始记日记」, 发出去就记下了。「撤回」删掉最后一条; 睡前说声「晚安」(或「结束」「今天就到这」)给今天收个尾, 它会回你一句晚安和今天的段数——不发也没关系, 跨天自动收尾; 「记：xx」把会被当命令的词原样记下; 「帮助」看全部用法。命令认人话: 「好，结束」「嗯 撤回」「晚安🌙」都听得懂。

  ![说「结束」, 它给今天收个尾](docs/images/daily-note.jpg)
- **「在吗」会得到状态回复**: 打招呼、探活这类消息不会被记进笔记, bot 会告诉你它在、今天已记几段。
- **熬夜不怕跨天**: 凌晨 4 点前记的都算前一天, 睡前的话属于"今晚"。
- **语音友好**: 语音消息由微信自动转写成文字, 带 🎤 标记入库; 转写失败也不丢——原始音频自动存进附件, 想要文字版再说一遍就行。设置里可开启**保存语音原声**: 开了之后笔记里是微信样式的语音条(点击即播)+下方转写文字, 存的是标准 WAV——手机上、卸载插件后照样能放(约 3MB/分钟, 计入库体积, 默认关)。

  ![语音气泡: 点击即播, 下面是转好的文字](docs/images/voice-bubble.png)
- **图片、文件、视频都收**: 发图/发文件(如 PDF 病历报告)/发视频, 自动存进 `日记/attachments/YYYY/` 并嵌入当天笔记, 文件保留原文件名;「撤回」同样撤得掉(只删笔记里的引用, 附件文件保留)。这是笔记不是网盘——文字为主, 附件为辅, 单个上限 100MB(微信通道的限制)。
- **每日提醒**: 到了你设的时间(默认 21:30), 今天还什么都没记的话, 它会在微信上轻轻提醒你一次; 记过了就不打扰, 连续 3 天没记就先安静下来等你回来。可在设置里关掉。
- **纯机械记录, 不经过任何 AI**: 原文直存, 一个字不改, 行为完全可预测。(设置里的 AI 配置暂未启用, 为将来的可选功能保留。)
- **数据只在你机器上**: 笔记是库里的纯 Markdown; 无作者服务器、无账号体系、无遥测。
- **只追加, 格式公开**: 历史段落永不被改写, 写入格式是一份公开契约([docs/data-contract.md](docs/data-contract.md)), 任何工具和 AI 都能读。

## 安装与绑定

**前提: 你的微信账号能用微信官方的 ClawBot 插件。** 本插件的扫码绑定走的就是这条官方通道(微信 → 我 → 设置 → 插件 → ClawBot 是它的入口), 腾讯自 2026-03 起逐步放量, 从未公布比例或全量时间。几条要点:

- 手机微信需 8.0.70 以上(iOS/安卓/鸿蒙均可)。
- **插件页显示「暂无可用的插件」不等于不能用**: 腾讯云团队的官方 FAQ 写明"即使尚未被灰度到, 直接对着微信二维码扫码也可以直接看到并使用"——灰度只影响入口可见性。所以先别等入口, 直接扫本插件设置页里的二维码试; 想看入口的话, 把微信从后台彻底关掉重开再进一次插件页。
- **用海外手机号注册的微信号(WeChat 账号)基本用不了**: 微信官方 3 月答疑"向微信用户开放, WeChat 用户暂时无法体验", 6 月腾讯员工称"已支持部分地区的 wechat 用户"(腾讯云 FAQ 只列出香港)。症状是扫码后提示"此账号暂时不支持该功能"或地区不支持, 见 [Tencent/openclaw-weixin#122](https://github.com/Tencent/openclaw-weixin/issues/122)。这是腾讯侧的账号地区限制, 与你人在哪里无关, 插件这边无能为力, 只能等腾讯开放。

1. 在 Obsidian 第三方插件里安装并启用(仅桌面端)。
2. 打开插件设置 → **扫码绑定** → 用手机微信扫码并确认。
3. 选好日记文件夹(默认 `日记`), 完事——给 bot 发条消息试试。

## 诚实的限制

- **能不能绑定取决于腾讯是否对你的微信号开放了 ClawBot**(见上节): 大陆手机号注册的微信号基本都能扫码绑定(哪怕插件页还没出现入口), 海外手机号注册的 WeChat 账号除少数地区外暂不支持, 插件本身对此无能为力。
- **仅桌面端, 且管道只在 Obsidian 开着时运行。** 电脑关机/睡眠期间发的消息不会丢: 下次打开 Obsidian 会按服务端游标自动补记, **24 小时内实测可补收**, 更长时间未测。
- 语音转写依赖微信自身; 转写失败时原始音频会存进附件(SILK 格式, 播放可能需要转换), 也可以重说一遍。
- **提醒是"尽力而为"**: 只在这台电脑开着 Obsidian 时发得出(到点没开机, 之后打开会补提醒); 微信通道对 bot 主动发消息的放行规则未公开, 偶尔可能发不出去。想要 100% 可靠的提醒, 建议在手机日历里加一条固定日程。
- 给 bot **转发**聊天记录/文件/公众号文章走不通——微信的转发列表里选不到 bot, 这是腾讯侧的限制; 文件请在与 bot 的对话框里直接发送。另: 微信重复发送同一个文件偶尔会加密出错, 插件会提示你改个文件名再发。

## 网络访问说明

本插件只与两类远程服务通信:

1. **腾讯 iLink bot 接口**(`ilinkai.weixin.qq.com` 及登录后服务端指派的地址; 二维码页面由腾讯域名提供)。这是微信官方的 bot 通道——插件扫码登录、长轮询拉取你发给 bot 的消息、回发回执。你的消息本来就经过微信/腾讯的基础设施, 与任何微信消息相同。对该接口的连接为直连(绕过系统代理), 因为该端点实际上拒绝代理 TLS。
2. **你自己配置的 OpenAI 兼容接口**——当前版本**未启用**: 即使配置了也不会发出任何 LLM 请求。设置项为将来的可选功能保留。

除此之外没有任何网络请求。无遥测、无统计、无作者运营的服务器。使用本插件需要一个微信账号(这正是插件的意义所在)。bot 绑定凭据与 AI Key 存放在 Obsidian 的密钥存储中——在库文件夹之外, 同步工具不会带走它们; 同步进度等非敏感状态存于插件的 `data.json`。

## 数据格式

```
日记/
├── 2026/
│   └── 2026-08-12.md
└── attachments/
    └── 2026/
        └── 2026-08-12-2305-a3f1.jpg
```

```markdown
---
date: 2026-08-12
weekday: 周三
source: wechat-diary
---

# 2026-08-12

**23:05**

今天试了新的手冲豆子, 花香很明显。

![[日记/attachments/2026/2026-08-12-2305-a3f1.jpg]]
```

完整规则见 [docs/data-contract.md](docs/data-contract.md): 只追加、北京时间(时区可配)、一次发送 = 一个 `\n\n` 分隔块 = 一条消息、「结束」写封存注脚。自契约 v1.2 起, 一天的边界是凌晨 4 点——4 点前的记录落在前一天的文件里。

前身 Python 常驻版 [wechat-diary](https://github.com/ArtemisLin/wechat-diary) 已归档(2026-08), 它写出的库遵循同一契约, 本插件可直接接着写。


## MiMo 文件转 Markdown（此 fork 新增）

这个 fork 保留原版“发什么记什么”的机械记录原则：普通日记、语音转写和附件保存**不会调用 AI**。只有你明确发送「转成 md」「把刚才的文件转成 Markdown」这类命令时，才会调用你自己配置的小米 MiMo API。

默认配置：

- 接口：`https://api.xiaomimimo.com/v1/chat/completions`
- 模型：`mimo-v2.5-pro`
- API Key：需要你在 Obsidian → WeChat Diary → **AI 文档转换 (MiMo)** 中自己填写，Key 仍使用 Obsidian Secret Storage 保存。

使用方式：

1. 在微信里把文件直接发给这个 bot（也可以文件和“转成 md”同一条发送）。
2. 再说「转成 md」或「把刚才的文件整理成 Markdown」。
3. 转换结果写入 `日记/converted/YYYY/原文件名.md`，原附件继续保留。

当前第一版只直接读取文本类文件：TXT、MD、CSV、TSV、JSON、YAML、HTML、XML、日志、配置文件和常见代码文本。**PDF、DOCX、PPTX、XLSX 暂不转换**：这些格式需要独立解析器；在没有可靠解析器前，插件会明确提示而不是把二进制内容交给模型或假装转换成功。

单文件暂限约 2MB / 60 万字符。这个限制是为了先把“微信文件 → Obsidian → 明确命令 → MiMo → 新 Markdown”这条主链稳定跑通，再扩展复杂格式。
